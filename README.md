# Margot à La Réunion

Carte 3D réelle de La Réunion (relief, satellite, bâtiments, vraies routes) avec les sorties classées par effort pour la cheville, l'agenda des fêtes jusqu'en mars 2027 et le réglage soleil/météo.

En ligne : https://v2b-studio.github.io/margot-reunion/

Tout tient dans `index.html` : données des lieux (`const S`), agenda (`const E`), style et code. Modifier, pousser, le site se met à jour en une minute.
